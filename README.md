# 🎬 استوديو الفيديو المجاني

اكتب لبوتك في تيليجرام ما تريد، فيصلك الفيديو جاهزاً في المحادثة. أي موضوع وأسلوب وطول، أفقي ليوتيوب أو عمودي للشورتس وتيك توك.

**كل شيء مجاني:**
- التشغيل: GitHub Actions (مستودع عام: 4 معالجات و16 جيجا، ودقائق بلا حد).
- النص: Gemini (طبقة مجانية، مفتاح بلا بطاقة).
- الصوت: edge-tts (أصوات عربية سعودية ومصرية وإماراتية، وإنجليزية).
- الصور: Gemini إن سمحت الطبقة المجانية، وإلا Pollinations المجاني.
- المقاطع الحقيقية المتحركة: Pexels (مجاني، ويُسمح استخدامها في يوتيوب).

## الأسرار (Settings → Secrets and variables → Actions)
| الاسم | من أين |
|---|---|
| `BOT_TOKEN` | من @BotFather في تيليجرام |
| `CHAT_ID` | يرسله لك البوت عند أول رسالة |
| `GEMINI_KEY` | https://aistudio.google.com/apikey |
| `PEXELS_KEY` | https://www.pexels.com/api/ (للمقاطع الحقيقية) |
| `POLLINATIONS_TOKEN` | اختياري: يرفع حد الصور المجانية |

## طريقتان للاستخدام
1. **تيليجرام:** أرسل لبوتك طلبك. يفحص الرسائل كل 5 دقائق تقريباً.
2. **GitHub:** Actions ← «اصنع فيديو» ← Run workflow (يبدأ فوراً).

حلقات الأطفال والاستوديو الكامل بالواجهة محفوظة في مستودع الموقع (studio_app).
